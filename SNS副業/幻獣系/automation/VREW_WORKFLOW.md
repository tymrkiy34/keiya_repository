## 制作手順

1. Computer Useスキルを読み、実際のVrewウィンドウを選択。最新画面を毎回確認して操作する。ユーザーのPC操作と衝突したら入力を重ねず調整する。
2. 新規作成 → テキストから動画を作成 → マイビデオスタイル「幻獣・妖怪」を選択。
3. ユーザー指定台本を入力する。台本の自動再執筆を行わない。通常の週次制作では校閲済みの約250字を用意して入力する。
4. 実際の画面で9:16、青山龍星、場面ごとの画像、短い字幕、BGMの設定を確認。保存スタイルから引き継いだ設定を優先し、勝手な別方式に変更しない。

   山彦試作で用いた画像指示: 日本の山彦の伝承を描く和風幻想画。各クリップの台本内容に合う異なる場面にする。霧の深い日本の山々、谷に声をかける旅人、声が返る山肌、岩や霧に溶け込む山の神や精霊の気配。藍と金、映画的な光、油絵の質感、神秘的で静かな雰囲気。同じ人物と画風を一貫させる。文字や図表、ロゴは描かない。反響は淡い光の波紋で表し、現代の機械や外国風の建物を入れない。
5. Vrew内で生成・編集し、画像と場面の一致、字幕、読み、音量を確認する。

   「短く」で字幕が単語単位に細かくなった場合は、編集 → 自動クリップ分割 → 全体クリップ → 最大20字 → 意味 → 分割を使う。山彦では71クリップが21クリップに整理され、11枚の場面画像とBGMが維持された。生成後に全クリップを選択したままホームの文字サイズを250から140へ変更。170では18～20字の字幕に不自然な折り返しが残り、140では最も長い20字の字幕もプレビューで1行に収まった。書き出しは「すべてのシーン、すべてのクリップ」、1080x1920を確認する。

   Windowsの保存ダイアログでtype_textが反映されなかった場合、最新画面を確認して入力欄にフォーカスし、英数入力モードに切り替えてキー入力する方法が使えた。今回の名前は既存連番に合わせて08。01～07を上書きしない。
6. 新しい名前で.vrewを保存し、Vrewの書き出し機能でMP4を保存する。元の01～07.vrewを上書きしない。
7. .vrewとVrewから出力したMP4の存在、内容・再生を確認し、タイトル・投稿文を添える。VOICEVOX:青山龍星など必要なクレジットを記載。
8. Vrewが使えない、認証・利用枠・ユーザー操作との衝突で進められない場合はその状態を記録する。Python/FFmpegでの代替制作を完成として報告しない。
