# Vrewで作り直した山彦

編集用ファイル: 動画/プロジェクト/08.vrew
完成動画: 動画/書き出し/08-yamabiko-vrew.mp4

Vrew 4.8.1の「テキストから動画を作成」を実際に操作し、保存済み「幻獣・妖怪」スタイルで制作。画像11枚、青山龍星、BGM「なんか凄まじい」、21字幕クリップ。9:16、1080x1920、約40.81秒。

字幕を意味単位・最大20字に整理し、文字サイズ140で不自然な1文字折り返しを修正。Vrewで保存とMP4書き出しの完了表示を確認。保存ダイアログの出力名08 (1).mp4を、完了後に08-yamabiko-vrew.mp4へ変更。

全体デコードでエラーなし、音声ストリームあり。Vrewの単語文字列と提供台本はかぎ括弧と改行を除き一致。生成時の全21字幕区間のフレームを確認し、最後の文字サイズ変更後は長い字幕と末尾の3区間を再確認。人間による通し試聴は未実施。

同階層の旧final.mp4はVrewを使っていない不採用試作であり、この完成動画と混同しない。投稿文・タイトル案は1つ上のmetadata.mdを使用できる。
