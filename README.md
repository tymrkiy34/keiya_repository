# 歯科医院 情報共有アプリ

スタッフ間でお知らせ・申し送り・予定などを共有する簡易Webアプリ（Node.js 18+、依存パッケージなし）。

## 起動

```
npm start        # http://localhost:3000
```

同じネットワーク内のPC・タブレット・スマホから `http://<サーバーのIP>:3000` で利用できます。
データは `data.json` に保存されます（`DATA_FILE` / `PORT` 環境変数で変更可）。

## 機能

- 投稿（カテゴリ: お知らせ / 申し送り / 在庫・発注 / 予定 / マニュアル、優先度: 通常 / 重要 / 緊急）
- 既読管理（誰が読んだか表示、未読フィルタ）
- ピン留め、削除、カテゴリ絞り込み、30秒ごとの自動更新

## 注意

- 認証はありません。院内ネットワークでのみ使用してください。
- 患者の氏名など個人情報は入力しないでください。
