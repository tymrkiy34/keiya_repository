# スマイル情報共有（歯科医院向け 情報共有アプリ）

スタッフ間でお知らせ・申し送り・予定を共有するWebアプリ。Node.js 22.9+、依存パッケージなし。

## 起動

```
npm start        # http://localhost:3000
npm test         # APIテスト
```

初回アクセス時に管理者アカウントを作成します。以降は管理者が「スタッフ」画面でアカウントを発行します。
同じネットワークのPC・タブレット・スマホから `http://<サーバーのIP>:3000` で使えます。

## 機能

- **ログイン**: ID＋パスワード（scryptハッシュ）、14日セッション、5回失敗で5分ロック、管理者/スタッフ権限
- **掲示板**: カテゴリ・優先度・ピン留め・検索・既読管理（誰が読んだか）
- **カレンダー**: 月表示、診療/休診/会議・研修/その他、終日・複数日対応
- **添付ファイル**: 投稿・予定にPDF/画像/Office/txt/csv/zip（1件10MB・10ファイルまで）。ログインした人だけダウンロード可
- **通知**: LINE・メールへ手動通知（投稿/予定作成時のチェック）＋前日17時に「明日の予定」を自動通知
- スマホ対応（下部タブ）・ダークモード対応

## 通知の設定

`.env.example` を `.env` にコピーして編集します（`npm start` が自動で読み込みます）。

- **LINE**: LINE Developers で Messaging API のチャネルを作成し、チャネルアクセストークンを `LINE_CHANNEL_TOKEN` に設定。`LINE_TO` にグループID/ユーザーIDを入れるとそこへ、空欄なら公式アカウントの友だち全員へ配信します。（LINE Notify は2025年3月に終了したため Messaging API を使用）
- **メール**: `SMTP_*` と `MAIL_FROM` を設定。スタッフが「設定」画面でメールアドレスを登録すると宛先になります。

設定後は「設定」画面の「テスト通知を送信」で確認できます。

## データと運用

- データは `data.json`、添付は `uploads/` に保存（どちらもGit管理外。バックアップ対象です）。
- インターネットに公開する場合は、HTTPSのリバースプロキシ経由にして `COOKIE_SECURE=1` を設定してください。
- 患者さまの氏名など個人情報は入力しないでください（画面にも注意書きあり）。
